Local LLM (On-Device Privacy)

Local LLM inference runs directly on your device's own hardware (via Meta Llama 3.2) for complete offline privacy.

ℹ️
Deployment Notice: On cloud-hosted servers, heavy local model weights are not hosted in the cloud.

How to run Local LLM on your PC:

  1. Install Ollama: Download free from ollama.com.
  2. Pull Model: Open terminal and run: ollama pull llama3.2.
  3. Run Locally: Run run.bat to chat with 100% on-device inference!
